# Rule: Evidence Labels

Source: `00-PROJECT-ONBOARDING/01_Project_Onboarding_Gate.md`.

Every statement in a stage artifact carries exactly one label:

| Label | Use when |
|---|---|
| CONFIRMED | Directly supported by a file in the repository or an approved artifact; cite it. |
| ASSUMPTION | Plausible but unverified; never used as the basis of a CONFIRMED conclusion. |
| PROPOSED | A suggestion by AI awaiting human approval. |
| UNKNOWN | No evidence available. Prefer UNKNOWN over a guess. |
| DECISION REQUIRED | Needs a decision from an authorized human. |

- NO EVIDENCE = NOT VERIFIED.
- Each CONFIRMED item must be traceable to its evidence (file path or recorded human decision).
